## Tentang

Saya Ibni Andarta, mahasiswa Teknologi Informasi di Politeknik Negeri Malang. Saya
memiliki spesialisasi dalam pengembangan aplikasi web end-to-end—mulai dari perancangan
basis data, pengembangan backend, hingga pengoptimalan antarmuka pengguna.

Beberapa proyek yang telah saya kembangkan antara lain SIMKAS (sistem informasi
pengelolaan kas kelas berbasis PHP dan PostgreSQL) serta Spada Scraper (alat scraper tugas
LMS SPADA terintegrasi dengan bot Telegram dan asisten AI yang di-deploy pada platform
Vercel).

<sub>Web &amp; software engineering · Malang, Indonesia</sub>

## Projects

### Spada Scraper

Scraper dan sistem manajemen tugas LMS SPADA Polinema. Portal web, bot Telegram, asisten
AI, serta pengingat deadline otomatis—berjalan sebagai serverless function di Vercel
dengan Redis.

<sub>Python · BeautifulSoup · Redis · Telegram Bot API · JWT · Vercel</sub>

[ live demo ↗ ](https://lms.ibni.me) &nbsp; <sub>[ private repo ]</sub>

### SIMKAS

Aplikasi pengelolaan kas kelas multi-grup dengan role admin, bendahara, dan anggota.
Mencakup tagihan, verifikasi pembayaran, transaksi, laporan, dan reset password via email.

<sub>PHP · PostgreSQL · JavaScript · CSS</sub>

[ repo ↗ ](https://github.com/Kakiow/PBL)

### Novelin

Web app lokal dan CLI untuk mengunduh chapter novel, lalu mengekspornya ke EPUB, TXT, atau
JSON. Antarmuka web untuk membaca, memilih chapter, dan memantau progres.

<sub>Python · Flask · BeautifulSoup · JavaScript</sub>
